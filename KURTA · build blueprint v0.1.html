πGlobal dtype rules

Four constraints make the rest of the document boring — in the best way.

Moneyamount_minor is signed cents (int) + ISO-4217 uppercase. Float money is a type error, not a style choice. Money.major exists only for display.
TimeUtcDatetime on every stamp: naive datetimes fail at validation, not silently in prod. UTC is the lingua franca; locale is a UI concern.
Identifiers^[a-z0-9_]{8,40} — opaque ULID-style, sortable, never PII-bearing.
IntegrityEvery citation, receipt, policy bundle and trace link is ^[0-9a-f]{64}$ by pattern; nothing says 'hash-ish string'.
Enumsverdict / gate / outcome / kind fields are closed enums. Free language lives in reason/basis fields only, so routing logic never parses prose.
extra=forbidEvery contract rejects unknown fields: upstream schema creep is a loud 422, not an ignored key.
Round-tripThe runner validates model_dump_json -> re-parse -> equality. A sample that cannot survive its own serialization is a bug in the model, not the sample.
